# APRON 07

机场地面运行指挥模拟：从落地到起飞，掌控每一次通行。

## 安装

```sh
npm install
```

## 本地启动

```sh
npm run dev
```

## Docker 启动

```sh
docker compose up --build
```

浏览器打开 http://localhost:8120 。

## 测试

```sh
npm test
```

无头仿真冒烟测试：完整通行链路、区块互斥、临时关闭三态、尾流间隔、
互相等待检测与安全解围、加速与存档恢复一致性。

## 跑道与滑行道系统

- **通行过程**：进近 → 分配机位 → 签发落地许可 → 跑道滑跑 → 经联络道 W
  脱离 → 滑行道 A → 机位 → 地勤保障 → 批准推出 → 滑行道 A → 联络道 E →
  跑道起飞。全程在真实路网上滑行，位置由（航路、区块、里程）决定。
- **互斥占用**：同一区块（跑道段/滑行道段/联络线）同时只允许一架航空器；
  接近交叉口（N1–N3 等节点）即占用节点，他人必须在道口前等待。
- **单向路段**：联络道 W 仅供到达脱离、联络道 E 仅供出发进入。
- **尾流间隔**：按前机/后机机型（宽体/窄体）与路段类型（跑道/滑行道）
  计算间隔，未满足不得进入。
- **两种许可**：全程许可一次性预留整条航路（占用更久）；分段放行逐段
  申请，可能中途等待。
- **等待与解围**：每架等待中的航班显示原因与受阻链条；出现互相等待时，
  检查器给出经仿真验证的安全解围项（撤销未进入许可 / 滑回机位 /
  解除后续预留），绝不让两机穿越。
- **临时关闭**：点击地图上的路段可关闭/重开。已获许可未进入者许可冻结
  等待；已进入者继续驶离；机位保障中的航班拿不到含封闭段的许可。
- **一致性**：所有占用、释放与尾流时刻都由模拟时钟驱动并随存档序列化，
  加速与读档后位置与占用状态始终一致。
